# Task: tutorial — Build an MCP server in TypeScript

## Brief

Hands-on tutorial: build a minimal MCP server in TypeScript from empty
directory to a working server a client can connect to. About 1,500–2,000
words plus code.

## Audience

TypeScript developers comfortable with Node, npm, and async code who have
never touched MCP.

## Constraints

- Every command must be runnable in sequence; every code block must be
  complete (no unexplained elisions).
- State SDK/version assumptions up front; flag anything version-sensitive.
- One troubleshooting section for the most likely failure.

## Sources

No supplied material. Official MCP TypeScript SDK docs expected.

## Hard requirements

- Starts from `npm init` (or equivalent) and ends with a connected client
  listing the server's tools.
- At least one tool implementation shown in full.
- Claims about commands/versions must be executable-checkable.
