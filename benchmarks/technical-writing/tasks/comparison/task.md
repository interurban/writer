# Task: comparison — Pairwise judgment vs 1–10 scores for writing

## Brief

Compare two evaluation methods for prose quality: pairwise comparison
against one criterion question vs absolute 1–10 scoring. Recommend one
for a writing harness. About 1,000–1,500 words.

## Audience

Engineers building evals for AI-generated content who know LLM-as-judge
basics (position bias, score compression, rubric drift).

## Constraints

- Fair to both methods: name what each is good for before recommending.
- No invented statistics (no "studies show 73%..."); reason from the
  measurement properties (comparability, bias surface, actionability).
- End with an operational recommendation, not a summary.

## Sources

No supplied material.

## Hard requirements

- Explains position bias and how each method handles it.
- Recommendation follows from the analysis (a reader can check the logic).
