# V1.1: the evaluation loop

> Measurement supersession: V1.2 ([v1-2.md](v1-2.md)) keeps this loop and
> makes its judgments evidence-backed — mandatory verbatim evidence spans,
> validation, one retry, and reproducibility capture. Read V1.2 for any run.

Answers *"does Writer actually improve technical writing at fixed model?"*
with blind evidence instead of new features. V1 capabilities are frozen;
the two behavior fixes below came from real evaluation runs, per the
milestone rule.

## What was built

- `bench/common.py`: seven dimensions, failure taxonomy, input-freeze
  prompts + sha256 audit, length-target parsing, opaque family helper.
- `bench/experiment.py`: `experiment` orchestration (60 runs default),
  isolated prime-home/sessions, `--mode json` event capture, article
  recovery (events → session fallback, never synthesized), manifest
  (commit, versions, models, seeds, input/harness hashes).
- `bench/economics.py`: token sums from `message_end` usage (no
  `turn_end` double count), session-file fallback, subagent attributions,
  Writer ledger metrics, citation URL lists. Nulls where Prime is silent.
- `bench/judge.py`: independent `--judge-model`, per-dim calls, verdict
  JSON parsing (errors recorded, never fabricated), family-match warnings.
- `bench/human.py`: interactive blind judging, reveal-after-submit.
- `bench/report.py`: per-criterion/task/category counts, economics
  medians + Writer/Vanilla ratios, `export.csv` + `economics.csv`.
- `bench/selftest.py`: ~35 no-model checks (both blind parities, verdict
  parsing, economics, freeze, tally, prompt blindness).
- Rust: explicit both-parities blind test in `pa-writer/tests/v1.rs`.

## Fixes from real runs

1. `length_in_range` was `false` for missing output; now null.
2. `collect_economics` derived the experiment id from path depth
   (`parents[3]`); now passed explicitly (found via selftest).

## Telemetry still unavailable

Per-call model breakdowns beyond attributions, cost (unless a usage
object carries it), judge-call tokens, citation brokenness (URLs listed,
not fetched). All nulled, listed in every report.

## Live status

No credentials in this environment (`~/.prime/agent/auth.json` is `{}`),
so the 60-run experiment, model judging, and human judging are built,
dry-run-validated, and plumbing-verified against the real binary — but
unexecuted. **No claim is made that Writer improves quality.** The exact
commands are in the benchmark README; artifacts will land under
`benchmarks/technical-writing/experiments/<id>/`.
